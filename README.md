## What Is This?

NOTHING is an unapologetically pointless single-page experience built with pure HTML, CSS, and JavaScript. It starts with a panda-branded splash screen, lands on a "NOTHING." announcement page, and lets you lose yourself in a handful of gloriously futile mini-experiences.

Zero cookies. Zero trackers. Zero point. Your time will not be refunded.

## Features

### 💥 Rage Typing — The Venting Void
Scream into a bottomless digital pit. Type your heart out, smash your keys, and release it into nonexistence. No database. No recovery. Just release.

- Live character counter
- Typing intensity meter (goes from *Zen* to *full meltdown*)
- "Release to the Void" ash-particle animation
- Your words vanish into thin air — forever

### ⭕ Circle Thing — Futile Physics
Drag useless floating circles into a slightly larger useless circle. Zero reward, zero satisfaction guaranteed.

- 6 draggable floating circles
- Drag-and-drop (pointer events) absorption mechanic
- Victory modal: "You accomplished absolutely nothing." Your reward is 0 XP, 0 dollars, and 30 seconds gone forever.

### 🪟 Mystery Window — Pointless Peephole
Open an interactive window to behold 12+ completely random, ridiculous, and underwhelming views of nowhere.

- Realistic 3D shutter animation
- 12 hand-written scenarios, including:
  - 🐦 *The Staring Pigeon* — "...coo."
  - 🧱 *A Solid Brick Wall* — "Why did you expect a view?"
  - 👨‍🚀 *Gerald the Astronaut* — "Have you seen mission control?"

  - and more…

### 🏆 Time Rescue Finale
Complete every useless activity and you'll be rewarded with confetti and a deeply satisfying **"You did absolutely nothing!"** celebration.

## Getting Started

### Run Locally

This is a dependency-free static site — just open it in a browser:

```bash
# Option 1: Double-click index.html, or serve it locally:
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

### Upload to GitHub Pages

The repo is ready to publish. From the repository's **Settings → Pages**, set the source branch to `main` (root), and your uselessness will be live at:

```
https://<your-username>.github.io/rage-typing/
```

## Tech Stack

- **HTML5** — semantic SPA-style views
- **CSS3** — responsive layouts, ambient glows, window shutter 3D animations, confetti, splash-screen transitions
- **Vanilla JavaScript** — view routing, drag & drop physics, particle effects, random scenario engine
- **Google Fonts** — Outfit & Space Grotesk

No frameworks. No build step. No dependencies. No point.
