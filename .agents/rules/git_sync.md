# Git Synchronization Rules

- **Repository**: `https://github.com/prittypramod/rage-typing.git`
- **Pre-Update Action**: Always run `git pull` before updating or modifying the codebase to stay synced with remote.
- **Post-Update Action**: Always run `git add`, `git commit`, and `git push` whenever changes or updates are made.
- **Persistence**: Maintain this repository connection persistently for the workspace.
